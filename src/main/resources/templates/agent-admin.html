Credential Setup

配置 MCP Token 加密主密钥

主密钥由系统部署者生成一次，普通用户无需知道。它只用于加密用户提交的 MCP Token。

  1. 在 PowerShell 生成 32 字节随机密钥 
    $bytes = New-Object byte[] 32
[Security.Cryptography.RandomNumberGenerator]::Create().GetBytes($bytes)
[Convert]::ToBase64String($bytes)
  2. 加入后端启动环境变量 
    MCP_CREDENTIAL_ACTIVE_KEY_ID=v1
MCP_CREDENTIAL_KEY_V1=上一步生成的Base64字符串
  3. 完全重启 Spring BootIDEA：Run Configuration → Environment variables。不要把真实密钥提交到 Git。
仅本地 MCP 开发

如需连接 localhost/http，可额外配置以下变量；生产环境保持 false。

MCP_ALLOW_PRIVATE_NETWORKS=true
MCP_ALLOW_INSECURE_HTTP=true

后端尚未配置 Token 加密主密钥。你仍可连接无需认证的 HTTPS MCP；Bearer Token 连接需要联系系统管理员完成后端配置。
